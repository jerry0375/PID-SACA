# Declaration of LLM Usage

This document outlines the scope and manner in which Large Language Models (LLMs) were utilized in the preparation of the paper **“PID-Controlled Constrained RL for Hub-based Joint Pricing, Dispatching, and Routing with Service Guarantees”** and its accompanying code repository. 

This declaration is made in full compliance with the **IJCAI-ECAI 2026 policy on Generative AI**.

## 1. Scope of Usage

We emphasize that LLMs were employed solely as **assistive tools** to enhance clarity and efficiency. They were **not** used to generate new scientific ideas, formulate the core methodology, or produce unverified experimental results.

### A. Text Rewriting and Polishing
* **Role:** The LLM served as an editor to improve the readability, grammar, and flow of the manuscript.
* **Process:** The authors provided the original drafts, detailed outlines, and specific technical arguments. The LLM was instructed to rephrase and expand upon these human-written inputs to meet academic writing standards.
* **Constraint:** The semantic content, logical flow of arguments, and technical descriptions originated entirely from the authors.

### B. Code Assistance
* **Role:** The LLM was used to assist with implementation details within a pre-defined software architecture.
* **Specifics:**
    * **Visualization:** Generating plotting scripts (e.g., `matplotlib` configurations) to visualize the training curves and pricing heatmaps.
    * **Refinement:** Optimizing syntax and debugging minor errors in the implementation of the PID control loop and environment interactions.
* **Constraint:** The core algorithmic logic (specifically the PID-Lagrangian update mechanism and the CMDP formulation) was designed and coded by the authors. The LLM did not generate the core algorithm "from scratch."

## 2. Methodology Integrity
We explicitly state that **no part of the research methodology was generated by an AI model.**
* The formulation of the **PID-SACA** algorithm is a human contribution.
* The design of the **Order Response Rate (ORR)** constraint is a human contribution.
* The LLM was **not** used as an agent within the experiment, nor was it used to generate synthetic ground-truth data.

## 3. Author Responsibility and Verification

The authors acknowledge full responsibility for the content of the paper and the code. To ensure accuracy and integrity:
1.  **Full Verification:** Every sentence rephrased by the LLM was reviewed by the authors to ensure it accurately reflected the original scientific intent without introducing hallucinations or errors.
2.  **Code Review:** All code snippets suggested by the LLM were tested, verified, and integrated manually by the authors.
3.  **Plagiarism Check:** The final submission has been checked to ensure no copyrighted text was inadvertently reproduced by the model.

We certify that this work represents our own intellectual contribution.
